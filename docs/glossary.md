# 术语

- **项目根目录**：真实 SVN 项目的公共工作副本根目录，也是 Codex 上下文的工作根。
- **项目**：管理器中的独立工作单元，由项目根目录、任务根目录、SVN 配置、任务记录和项目运行状态组成。
- **项目身份**：由项目根目录规范化真实路径计算的稳定标识。相同 SVN URL 的不同本地 checkout 可以拥有不同项目身份。
- **项目索引**：应用级记录，保存已登记项目的身份、显示名称、路径和最近使用信息；不保存项目运行状态。
- **项目运行锁**：按项目身份创建的 Windows named mutex，保护 junction、SVN 工作副本、任务文件和项目状态不被多个写进程同时修改。
- **GUI 会话锁**：按项目身份创建、由 GUI 窗口整个生命周期持有的锁，只用于阻止同一项目出现第二个 GUI 窗口。
- **项目操作锁**：按项目身份创建、只在一次写操作期间持有的锁，串行化 GUI 与 CLI 对 junction、SVN 工作副本、任务文件和项目状态的修改。
- **项目影响范围**：项目根目录、任务根目录以及任务映射目录实际会读写的规范化路径集合。不同项目的影响范围不能重叠。
- **项目上下文**：绑定到一个项目窗口或 CLI 操作的不可变身份和路径集合，供 `WorkspaceStore`、`WorkspaceService`、日志和 Codex 上下文共同使用。
- **任务根目录**：任务独立工作副本的根目录，通常只包含配置的任务映射目录。
- **任务映射目录**：由配置指定、可在项目目录和任务目录之间切换目标的相对路径。
- **路径映射**：`pathMappings` 中从项目相对路径到当前实际编辑目录的关系。
- **任务映射模式**：GUI 使用 junction 将项目任务映射目录指向活动任务的模式。
- **Codex 编辑上下文**：Skill 根据 CLI 返回的工作根和路径映射建立的当前会话编辑边界，不改变 GUI 映射模式。

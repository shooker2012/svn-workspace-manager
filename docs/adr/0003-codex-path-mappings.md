# Codex 编辑上下文使用项目根与任务映射目录路径映射

## 决策

Codex 上下文始终以项目根目录作为工作根。配置中的任务映射目录通过 `pathMappings` 替换为实际编辑目标：普通模式指向项目目录，任务模式指向任务工作副本。项目根下的公共文件保持原路径。

`codex context --normal` 只返回普通模式上下文，不修改管理器状态、SVN 工作副本或 junction。

## 原因

管理器只负责配置的任务映射目录。任务工作副本也只 checkout 这些目录，因此不能把任务根目录误认为完整项目副本。路径映射可以同时表达公共文件和任务映射目录中的文件，避免 Skill 根据任务名自行拼接路径。

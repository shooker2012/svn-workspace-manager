# SVN 工作区管理器图标候选

预览图：[icon-candidates.svg](./icon-candidates.svg)

- A：任务分层。用三层卡片表达任务、工作区和映射关系，适合突出任务管理。
- B：目录映射。用两个目录和中间箭头表达原目录与任务目录之间的映射，含义最直接。
- C：SVN 同步。用循环箭头、时钟和节点表达更新与版本同步，SVN 工具属性最明显。
- D：工作区节点。用中心节点连接多个任务节点，突出多个任务共用测试入口的特点。

候选图用于比较设计方向。

已选定 A。正式资源为 `src/SvnWorkspaceManager.Gui/Assets/app-icon-a.svg`、`app-icon-a.png` 和 `app-icon-a.ico`，并已接入 GUI 窗口和 Windows 应用图标。
